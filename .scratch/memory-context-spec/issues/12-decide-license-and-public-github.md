# Decide license and public GitHub

Type: grilling
Status: resolved

## Question

What license does TinyMem publish under, and what does “open source” mean for v1: a public GitHub repository now, after the spec, or another host and timing?

## Answer

**MIT**, as already in `LICENSE` and `pyproject.toml`. Public source lives on **GitHub**. This map does not create the remote. After the spec is decision-complete, the first implementation step is a public GitHub repository under MIT. PyPI is later, not this spec’s publish bar. No open-core split.
